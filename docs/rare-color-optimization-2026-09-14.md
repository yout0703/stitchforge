# 少量线色合并

本轮针对普通图片生成后“某种线色只有少数针，却额外增加换线”的问题，新增全局配方精简。原有优化只尝试最多 3 针的连通块；新增步骤在其后运行，评估一种少量线色的全部针脚，满足条件才整体并入相邻常用线色。

## 当前规则

- 候选线色最多占实际非空针数的 1%，且不超过 128 针；空白画布不计入分母。
- 目标必须是常用线色，并与至少 60% 的候选针脚四邻域相接；不会仅因远处存在近似色就合并，也不连续合并多个少量色形成色偏。
- 配方股数相同；屏幕近似色的 CIEDE2000 距离不超过 6，任一针脚相对原始采样的色差增加不超过 2。
- 任一针脚处于 locked／preserve 区域，或碰到透明轮廓、画布边缘，保留该线色。
- 使用八邻域检查连续细线，保留横线、竖线、斜线及稀疏长结构。这是保守几何规则，不是物体语义识别。
- 成功合并后仅删除被合并配方与对应图例；保留其余配方索引和符号，以及材料来源记录。

这些阈值是可调整的工程默认值，尚未经过实体绣线校准；不按针数强制删色。严格数针还原分支继续保留已识别的独立线色，`optimize=false` 也跳过本步骤。

## 可见结果与追溯

生成后右侧显示“线色精简”，包括生成时的颜色数变化、改动针数，以及未满足条件而保留的少量线色数量。摘要写入版本的 `extensions["stitchforge.rare_colors"]`，刷新仍可查看；显示的是生成时结果，后续手工编辑不会改写这份记录。

完整 `rare_color_report` 包括每种合并的源／目标配方索引、针数、色差和保留原因，随转换报告存入不可变产物，并记录新算法文件哈希。原图和历史版本保留。本步骤用于新生成任务，已有图纸不会被后台批量改写。

## TDD 验证

先添加引擎用例，确认缺少实现时失败；实现后 12 项引擎测试通过。再添加真实 API 的启用／关闭用例，以及精确数针分支断言，先观察到缺少 `rare_color_report` 的 3 项失败，再接入流程。浏览器用例先确认缺少精简说明而失败，再实现显示和刷新恢复。

覆盖：相近的 4 针色块可以减少一种线色；深色细节、横向／斜向细线、透明边界、locked／preserve、不同股数、仅远处存在的近似色、原图误差过大均保留；检查有效针数分母、不修改输入、重复运行稳定、配方与图例一致、关闭优化、报告随版本与产物保存。
