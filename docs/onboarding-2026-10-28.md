# 首页接续与控件验收（2026-10-28）

本轮将登录门槛移到用户选择制作方式之后，沿用蓝白工作台与现有刺绣素材。

## 用户流程

1. 未登录访问首页，直接看见「导入已有图纸」「图片转图纸」及空白绘制入口。
2. 导入或图片入口先选择文件。支持文件选择、拖放、大小与格式检查、移除 / 更换，图片显示预览。
3. 用户点击「登录后继续」，登录弹窗显示已选文件名。可以切换注册 / 登录、返回文件选择或退出到首页。
4. 登录成功自动打开原操作的确认弹窗，文件仍在，无需重新选择；没有自动上传或生成。
5. 用户明确确认后才调用原有导入 / 生成接口。图片生成次数不足时保留文件，并说明次数限制。

选好的文件只保留在本页内存中，不写入 localStorage / IndexedDB；刷新、关闭页面或退出登录后需要重新选择。登录前只是文件类型和大小预检，真正的文件内容与兼容性仍由服务端校验。

## 组件

- `PublicHome`：公开首页、制作路径与独立登录入口。
- `StartFileDialog`、`AuthDialog`：原生模态框，明确文件上下文与前后步骤。
- `FilePicker`：隐藏原生文件按钮的系统文案，仍通过真实 file input 打开系统文件选择器。图片对象 URL 在替换 / 卸载时释放。
- `SelectControl`：统一排序和 XSD 编码选择样式，保留原生 select 的可访问性及键盘行为。
- App 的导入弹窗切换为原生 dialog；不再手写焦点循环，背景由浏览器保持不可交互。
