# 十字绣真实图回归样本

这组样本从本机 `amazing-images-creator` 项目的既有十字绣保真度实验中复制，供
StitchForge 做可重复的真实图片转换回归。每组包含输入效果图、旧流程效果预览、
旧流程图纸预览与指标报告。文件哈希和原目录记录在 `manifest.json`。

| 样本 | 主要覆盖场景 | 目标网格 | 颜色预算 |
| --- | --- | ---: | ---: |
| `parakeets` | 高饱和羽毛、花朵、细碎轮廓 | 120 × 180 | 30 |
| `folk-owl` | 对称几何、深色轮廓、民俗纹样 | 140 × 210 | 23 |
| `lucky-rabbit` | 浅色主体、低对比渐变、接近底布的白色 | 120 × 180 | 23 |

这些文件只作为本地算法回归素材，不代表 StitchForge 采用旧项目的色库、CT 或股线
规则。基准运行仍使用 StitchForge 当前 DMC 色库和算法。
